The user (Taylor Hadfield) describes OdysseyEngine's target register as **"Fantasy Etherealism Impressionism"** paired with the engineering commitment **"everything understood."** These two labels sit behind the v0 Vibe Charter.

**How to apply:**
- When drafting or challenging felt-experience proposals, read "ethereal" as *atmospheric / hazy / tonal* — NOT as "hard-edge fantasy" or "high-fantasy heroic." The Halo-lineage composer and Evangelion HUD are on-register; UE5-marketplace fantasy is not.
- "Impressionism" is a hint against photoreal surface detail and toward compositional, painterly, legibility-first rendering. This is why Pillar 3 (legibility over spectacle) and the anti-PBR Forbidden entries exist.
- "Everything understood" is both engineering discipline and aesthetic commitment — the engine's look is inseparable from the fact that we wrote every line. Use this when a proposal tries to import an opaque library for "better visuals."
- The user values terse, concrete language in responses. No filler, no emojis, no trailing summaries unless a report was requested.
- The user collaborates through agents in parallel; expect council votes on non-trivial proposals rather than solo decisions.
